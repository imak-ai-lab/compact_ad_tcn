# Resource-Aware Compact Anomaly Detection for Bearing Condition Monitoring: A Family-Level Pareto Study with Lightweight TCN Forecasting

Source code of the paper by I. Andrianov, A. Kovalenko and I. Makarov.
The original code is also available at [crazyilian/industrial_ad](https://github.com/crazyilian/industrial_ad).

## Structure

- `industrial_ad/`: datasets (Paderborn, CWRU), features, models, training, anomaly scoring, quantization
- `runners/`: hyperparameter sweeps, one script per model family
- `quantize.py`, `benchmark.py`: post-training int8 quantization and CPU latency benchmark
- `summary_table.csv`, `summary_table_quant.csv`: results of all float32 and int8 runs
- `scripts/`: paper tables, seed reproduction (`phase0`), baseline detectors (`phase1`), CWRU (`phase2`)
- `mcu/`: deployment on STM32H755 (NUCLEO-H755ZI-Q): host scripts, firmware sources, measurements
- `analyses/`: label-free checkpoint selection, thresholds, unseen operating condition

## Requirements

PyTorch and `pip install -r requirements.txt`.
For `mcu/`: `mcu/requirements.txt`, ST Edge AI Core 10.2, Arm GNU Toolchain 14.2, STM32CubeProgrammer.
Code generated by ST Edge AI Core and the HAL/CMSIS sources are not included.

The Paderborn and CWRU data are downloaded by `industrial_ad/datasets/*/download.py` and are not included.
